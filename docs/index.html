JSON Debugger

Paste JSON, point at an array, and filter rows with a short JavaScript expression—right in your browser.

Open JSON Debugger Source on GitHub

How to use

  1. Open the app using the link above (hosted at jsondebugger.vercel.app).
  2. Paste your JSON into the input panel. Your data stays in the page; nothing is sent to a server.
  3. Set the array path if your list is nested—for example data.orders. Leave it blank if the top-level value is already an array.
  4. Write a filter as item => … using the expression body only, e.g. item.resultCode !== 0 or item.status === "failed".
  5. Review matches in the tree or raw view, and use copy result to copy the filtered JSON.

This page is for GitHub Pages. The live tool runs at https://jsondebugger.vercel.app/.
